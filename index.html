What this is

Reusable tavern chrome — no build required

This hall documents the Rosebrook look so future storefronts, Etsy tiles, and guild tools can share one voice. Link the CSS. Copy a component. Serve the files as a static site.

No React. No Vite. No Storybook. Open the HTML, or point Coolify at the repo root.

How to use

Link the files and keep walking

<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Cinzel:wght@400;600;900&family=Cinzel+Decorative:wght@400;700&family=Crimson+Text:ital,wght@0,400;0,600;1,400;1,600&display=swap" rel="stylesheet">
<link rel="stylesheet" href="css/rosebrook.css">

Need only the pigments? css/tokens.css. Building a new control? Start from css/components.css. This docs skin (css/docs.css + js/docs.js) stays in the hall — leave it behind when you furnish a shop.
